**Core Stack:** JavaScript, Solidity, HTML

### Key Contributions:
- Researched and learned Ethereum, Solidity, and OpenZeppelin development frameworks independently.
- Implemented smart contracts using OpenZeppelin's ERC721 standard library for non-fungible token minting and trading.
- Leveraged `web3.js` and `ethers.js` libraries for seamless communication between the React frontend, MetaMask wallet, and smart contracts.
